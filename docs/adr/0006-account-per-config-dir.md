# One Claude config dir per Account

Claude Code keeps only the active login on disk, so re-running `/login` in one dir leaves every other Account untrackable. We track extra Accounts through separate Claude config dirs (`CLAUDE_CONFIG_DIR=~/.claude-work claude`), discovered from `~/.claude` and `~/.claude-<name>` plus any `CLAUDE_CONFIG_DIR` entries, and labelled or hidden in Settings. We rejected holding our own copy of each login's tokens (a second refresher racing Claude Code over the same refresh token, and a new secrets store to defend) and relying on Claude Swap alone (third-party, and all its Accounts share one log dir, so Spend cannot be split). Config dirs are the only arrangement where both Quota and Spend come out right per Account: each dir belongs to exactly one Account, so its session logs are attributed once and Total Spend never double-counts. Account labels never carry the email address, on the Dashboard or the Bar strip.
