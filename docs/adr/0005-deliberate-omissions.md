# Deliberate omissions from upstream parity

The port matches upstream behaviour except: no telemetry (no backend to receive it, and it would be a new processing activity for no gain), no iCloud-equivalent sync, no Hide From Screen Share, no haptics, no Light/Dark appearance switch — the Omarchy theme is the only palette — and no Increase Transparency, since Omarchy/Hyprland layer rules own opacity (party mode becomes a theme-colour cycle instead). Anyone "restoring" these should know they were dropped on purpose.
